# Pollux 暑假作業

這是一個可持續增加分頁的靜態暑假作業網站。

## 網站結構

- `index.html`：作品收藏主頁。
- `home.css`：主頁樣式。
- `bear-farm.html`：第一份作品「日本熊熊大調查」。
- `styles.css`、`app.js`：熊主題分頁的樣式與互動。

## 新增下一份作業

1. 在根目錄加入新的 HTML 分頁，例如 `my-new-project.html`。
2. 在 `index.html` 的 `.project-grid` 中加入一張作品卡片，連結到新分頁。
3. 更新主頁「目前收錄」的作品數量。

所有核心檔案均使用相對路徑，可直接雙擊 `index.html` 離線閱讀，也適合放在一般靜態網站空間。
